# 3D mascot artwork

The files in this directory are 17 WebP 3D cartoon animal portraits from **Animoon**, by smnandre.
Original: https://github.com/smnandre/animoon
License: **CC0 1.0 Universal**. The original license text is included in `CC0-LICENSE.txt`.

This image pack is separate from the original generated game UI mockups. Existing mascot identities and progress data remain unchanged. Identical animal art may be reused by multiple mascots with different roles; other species retain individually generated vector portraits until matching 3D art is available. Do not describe the 145 entries as 145 unique raster images.
